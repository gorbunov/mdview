# MdView

A fast, reader-first Markdown viewer for macOS, in the spirit of Preview.app: double-click a `.md` file and read it in a calm, book-like layout, with an explicit edit mode for quick corrections.

**[Download the latest release](https://github.com/gorbunov/mdview/releases/latest)**: free, signed and notarized, macOS 14 or later. Open the DMG and drag MdView to Applications.

- GitHub-flavored Markdown with alerts, syntax highlighting, KaTeX math and Mermaid diagrams
- Live reload, outline sidebar, find, zoom, print and PDF export
- Folder workspaces with contents navigation and tabs
- Quick edits in a native Markdown source editor
- Quick Look preview in Finder (press Space on a `.md` file)
- Fully offline; scripts inside documents never run

MdView updates itself (MdView → Check for Updates…). This repository hosts the release downloads and the update feed (`appcast.xml`).
